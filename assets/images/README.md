# Zdjęcia do archiwum

W tym folderze dodawaj zdjęcia, które wykorzystamy na stronie.

Na GitHub otwórz `assets/images`, wybierz **Add file → Upload files**, przeciągnij zdjęcia i zatwierdź przez **Commit changes**.

- Używaj plików JPG, PNG lub WebP.
- Nadawaj krótkie nazwy bez spacji i polskich znaków, np. `crisuuubtkj.jpg`.
- Dodawaj tylko materiały, które chcesz publicznie udostępnić. W publicznym repozytorium zdjęcia są widoczne dla wszystkich.

Po dodaniu zdjęcia podaj jego nazwę i miejsce na stronie, w którym ma się pojawić. Samo wgranie pliku nie dodaje go automatycznie do galerii ani do karty osoby.

Ścieżka w stronie: `./assets/images/crisuuubtkj.jpg`.
